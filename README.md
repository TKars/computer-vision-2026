## Baseline ViT на 95/5

15 октября запущен `output/pretrained-vit-95-20261015`: 655500 train / 34500 val, по 1900/100 рисунков каждого класса. `split95.py` оставляет по 100 рисунков каждого класса из прежнего val с seed 45, сохраняет индексы и SHA256 в `input/split95-seed45`. Исходные данные не меняются. Старый полный val после переноса части данных в train больше не используется для оценки новой модели.

ViT-S/16 `vit_small_patch16_224.augreg_in21k_ft_in1k` начинается с внешних pretrained-весов. Вход 224×224, один канал, batch 64, AdamW 0.0001 / 0.001 для головы, weight decay 0.01, EMA 0.99, BF16. Cross-entropy с label smoothing 0.05, без дополнительных loss. До 10 эпох с бюджетом 3 часа; 15 минут оставлены на inference.

`pretrained_vit.py --data-dir input/split95-seed45` использует новую разбивку; без аргумента сохраняется прежняя. Полный `last.pth` обновляется атомарно каждую минуту и после эпохи, завершённые эпохи сохраняются в `epoch-NN.pth`, лучшие веса — в `vit.pth`. Checkpoint содержит также AdamW, EMA, RNG и положение внутри эпохи. При продолжении через `--resume` проверяется совпадение разбивки.

На оставленных 34500 val прежний ViT даёт 76.1304% plain и 76.4145% flip, EfficientNet — 76.2522% flip. Это ориентиры для сравнения нового запуска на одинаковых примерах. Его результаты будут в `history.csv`, `scores.csv`, `summary.json` и [vit95_results.ipynb](vit95_results.ipynb). После обучения отдельный процесс повторяет весь val/test и проверяет submission.

Разбивка и соответствие файлов индексам проверены независимо. GPU smoke и восстановление всех состояний AdamW прошли; отдельный inference воспроизвёл submission без различий. Это технические проверки на 64 примерах, не метрика нового полного обучения.

## Батчи с похожими классами

Подготовлен отдельный вариант в `similar_batches.py`, выключенный по умолчанию. При batch 64 он берёт 48 обычных примеров и 16 из одной похожей пары, по 8 каждого класса. Пара выбирается равновероятно из `similar_pairs.json`. Внутри батча изображения не повторяются; между батчами повторы разрешены. Размер эпохи остаётся 655500 выборок, поэтому часть train в конкретной эпохе может не встретиться. Частоты классов меняются: это целевое oversampling, а не сохранение прежнего баланса.

`make_similar_pairs.py` выбирает пары по сохранённым предсказаниям прежних моделей только на 69000 примерах, перенесённых в train. Оставшиеся 34500 val в этом расчёте исключены. Требуется не менее 14 взаимных ошибок plain ViT и не менее 10 у flip ViT и EfficientNet. Получилось 149 пар с участием 189 классов. Используются прежние checkpoint, ранее выбранные на старом val; новая разбивка не становится независимым тестом.

Loss остаётся cross-entropy с label smoothing 0.05. Соседство рисунков в батче не добавляет pairwise-loss: для ViT с LayerNorm основное изменение — частота показа трудных классов и состав градиентных шагов. Улучшение accuracy ещё не проверено обучением.

После baseline можно запустить отдельный опыт с теми же pretrained-весами и остальными настройками:

```bash
.venv/bin/python -u pretrained_vit.py --data-dir input/split95-seed45 --similar-pairs similar_pairs.json --epochs 10 --deadline "$(.venv/bin/python -c 'import time; print(time.time() + 10800)')" --output output/pretrained-vit-similar-95
```

Checkpoint сохраняет SHA256 и копию списка пар. Продолжение собственного sampler-прогона подхватывает этот список и восстанавливает последовательность батчей; смена sampler через `--resume` запрещена. Для сравнения с baseline нужен отдельный запуск. Проверки на CPU:

```bash
CUDA_VISIBLE_DEVICES= OMP_NUM_THREADS=1 .venv/bin/python test_similar_batches.py -v
```

Проверены вся эпоха, неполные батчи, отсутствие повторов внутри батча, воспроизводимость и порядок после resume, сохранение прежнего random sampler. Список пар независимо пересчитан по перенесённым train-примерам. GPU-обучение с новым sampler не запускалось; текущий baseline работает без изменений.

`train.py` проверяет выданный baseline на полном validation, сравнивает два ResNet18, дообучает лучший и сохраняет submission. `quick_draw.ipynb` запускает тот же код из Jupyter.

Оба ResNet начинают с `baseline.pth`. Входная свёртка имеет размер 3×3 или 7×7, stride=1; начальный max pooling убран. Для 3×3 используется центральная часть исходного ядра. Остальные веса сохраняются. Изображения остаются 28×28.

`quick_draw_kaggle.ipynb` — прежний эксперимент с моделями ширины 32 и 64, обучаемыми с нуля.

## Эксперименты

Обучение использует только train. Каждый вариант получает одинаковый лимит времени и не более 40 эпох: AdamW, lr=0.0003, weight decay=0.0001, cosine schedule, label smoothing=0.05. Победитель получает до 30 дополнительных эпох с lr=0.0001. Часть времени оставляется на проверку и inference.

Поворот до 10°, сдвиг до 5%, масштаб 0.9–1.1 и горизонтальное отражение применяются отдельно к каждому изображению на GPU. Используется AMP. На каждой эпохе вычисляется accuracy на всём validation без аугментаций, сохраняются метрики и лучшие веса.

В конце сравниваются одиночные модели, усреднение original/flip и ансамбль двух вариантов. Способ получения submission выбирается по validation, test используется только для предсказаний.

В папке запуска сохраняются `history.csv`, `scores.csv`, веса, `config.json`, копия исходного кода, `summary.json`, вероятности на validation и `submission.csv`.

В условии порог для 6 баллов — строго выше 0.76102, для 8 — строго выше 0.77489. Отдельного порога для 7 нет. Проверка этих порогов на validation помогает выбрать модель; баллы зависят от результата на Kaggle.

Исходный baseline на полном validation на GPU: 70182/103500 = 0.67808696. CPU-проверка дала 70178/103500 = 0.67804831.

## Дополнительная регуляризация

Если первого эксперимента недостаточно, `improve.py` обучает ResNet18 на входе 56×56 с исходными stride и pooling, начиная с `baseline.pth`. Изображения увеличиваются билинейно. Используются Mixup с alpha=0.2 и AdamW с weight decay=0.01.

```bash
.venv/bin/python -u improve.py --parent output/run --output output/resize56 --minutes 60
```

Второй вариант дообучает лучший checkpoint первого эксперимента с той же регуляризацией:

```bash
.venv/bin/python -u improve.py --parent output/run --output output/regularized --kind parent --minutes 45
```

В конце BatchNorm пересчитывается на 51200 случайных train-примеров без аугментаций. Изменение сохраняется только при улучшении validation. Затем проверяются flip TTA и ансамбль с лучшим результатом первого эксперимента.

Mixup смешивает две картинки и вычисляет loss как взвешенную сумму потерь по их меткам. В логах train accuracy считается по метке картинки с большим весом. Основной критерий сравнения — полный validation.

## Финальный ансамбль

`ensemble.py` сравнивает сохранённые модели, пары и усреднение трёх или более моделей на полном validation. Для каждой пары проверяются веса 0.25/0.5/0.75 и температуры 1/2/4. Для трёх или более моделей проверяется равномерное усреднение и вес 0.5 у каждой модели по очереди. Температура меняет уверенность предсказаний, не обучая веса сети. Выбранная комбинация целиком сохраняется в `summary.json` и применяется к test.

```bash
.venv/bin/python ensemble.py --runs output/run-20261014 output/resize56-20261014 output/regularized-fixed-20261014 --output output/ensemble-20261014
```

В `--runs` перечислить только завершённые запуски с `summary.json`. В результатах указаны точное число верных ответов и размер validation.

## ViT с нуля

`vit.py` обучает один ViT на тех же рисунках 28×28: патчи 4×4, 49 патчей, размер признаков 192, 6 блоков, 3 головы attention, усреднение выходных признаков. В модели 2749209 параметров. Начальные веса случайные, внешние данные и pretrained weights не используются.

AdamW с lr=0.001 и weight decay=0.05; bias, LayerNorm и позиционные параметры не получают weight decay. Первые 5 эпох используются для warmup, затем lr убывает по cosine до 0.00001. Число эпох оценивается по времени первой эпохи, обучение ограничено общим временем. Последние десять минут оставлены для проверки и submission.

Аугментации совпадают с ResNet. Дополнительно используются Mixup с alpha=0.2, label smoothing=0.05, DropPath=0.1 и ограничение нормы градиента до 1. Mixup отключается в последних десяти плановых эпохах. EMA с decay=0.999 усредняет параметры в ходе обучения; лучший одиночный checkpoint выбирается между текущими весами и EMA по полному val. Предсказания разных моделей не усредняются.

Для сравнения взят лучший одиночный ResNet из предыдущих прогонов: `output/regularized-fixed-20261014/model.pth`. Перед обучением ViT он заново проверяется на тех же 103500 val-примерах. В итоговой таблице для обеих моделей есть обычный inference и одинаковый flip TTA.

```bash
.venv/bin/python -u vit.py --output output/vit-20261014
.venv/bin/python vit.py --verify --output output/vit-20261014
.venv/bin/jupyter lab vit_results.ipynb
.venv/bin/python pack.py output/vit-20261014 --archive Карсалиев_Тимур_HW_2_ViT.zip
```

Обычный запуск ограничен тремя часами. `--deadline` задаёт абсолютный Unix timestamp окончания. `--smoke` проверяет весь процесс на 512 train и 64 val/test, результаты этой проверки не относятся к соревнованию. Полный запуск сохраняет реальные метрики в отдельной папке; прежние результаты ResNet остаются доступны.

Проверить flip TTA во время обучения можно на отдельной сохранённой копии лучшего checkpoint. Оба варианта используют один полный val:

```bash
.venv/bin/python vit_tta.py --output output/vit-tta-check
```

Копия весов, метрики и номер эпохи сохраняются в указанной новой папке.

Разбор ошибок по классам использует сохранённые вероятности на val:

```bash
.venv/bin/python class_errors.py --predictions output/vit-tta-check/val_flip.npy --output output/class-errors
```

Сохраняются accuracy каждого класса, матрица ошибок, частые путаницы и примеры уверенных ошибочных предсказаний. Разбор относится к конкретному checkpoint, указанному в папке проверки TTA.

## Pretrained ViT

Предыдущий ViT с нуля остановлен по запросу пользователя после 89 эпох. Лучший сохранённый checkpoint: EMA эпохи 87, accuracy 0.74065700 на 103500 val без TTA. Его веса и история сохранены отдельно.

`pretrained_vit.py` дообучает `vit_small_patch16_224.augreg_in21k_ft_in1k`: внешние веса ImageNet-21k → ImageNet-1k из timm. В модели 21601881 параметр, 12 блоков, 6 голов, размер признаков 384. Вход увеличивается с 28×28 до 224×224 бикубически; патчи 16×16, 196 патчей. Рисунок инвертируется в чёрные линии на белом фоне, значения нормализуются через mean=0.5, std=0.5. timm адаптирует входную свёртку к одному каналу, новая голова содержит 345 классов.

Для дообучения используется только выданный train. Внешние pretrained-веса разрешены пользователем отдельно. Val используется для выбора checkpoint и flip TTA, test — для предсказаний.

AdamW: lr=0.0001 для backbone и 0.001 для новой головы, weight decay=0.01, warmup половину эпохи и cosine schedule. Batch size 64, bfloat16 autocast, label smoothing=0.05, EMA=0.99. Из аугментаций используются прежние повороты, сдвиги, масштаб и flip; Mixup отключён. Новый запуск сохраняется отдельно от предыдущих результатов.

```bash
.venv/bin/python -u pretrained_vit.py --output output/pretrained-vit-20261015
.venv/bin/python pretrained_vit.py --verify --output output/pretrained-vit-20261015
.venv/bin/jupyter lab pretrained_results.ipynb
```

`--deadline` задаёт общий лимит абсолютным Unix timestamp. Последние 15 минут оставлены для полного val/test и отдельной проверки. Для inference повторно загружать внешние веса не нужно: модель создаётся с `pretrained=False` и загружает локальный `vit.pth`. Сравнение с лучшим одиночным ResNet использует тот же полный val, отдельно без TTA и с flip TTA.

## Продолжение ViT

Первый pretrained-запуск был прерван после пяти полных эпох. Последние доступные веса — EMA эпохи 5: 0.75759420 на полном val без TTA. Состояние оптимайзера этого запуска не сохранилось. Продолжение начинается с этих весов, нового AdamW и lr=0.00003 для backbone / 0.0003 для головы; метрика загруженных весов повторно проверяется перед обучением.

```bash
.venv/bin/python -u pretrained_vit.py --resume output/pretrained-vit-20261015 --output output/pretrained-vit-resume-20261015
```

Новый запуск по умолчанию ограничен двумя часами, включая финальную проверку. Старые файлы сохраняются. Полное состояние записывается в `last.pth` каждую минуту и после каждой эпохи: веса, AdamW, EMA, номер эпохи и батча, история и состояния генераторов случайных чисел. Запись заменяется атомарно после сброса на диск. `checkpoint.json` показывает последнюю сохранённую позицию. Лучшие веса по val хранятся отдельно в `vit.pth`.

При следующем продолжении `--resume` автоматически выбирает `last.pth`, если он есть. Восстанавливаются оптимайзер и EMA, порядок примеров воспроизводится по номеру эпохи, уже обработанные батчи пропускаются. Новый cosine schedule начинается с сохранённого learning rate и использует новый лимит времени. Автоматическое выключение ПК в этот запуск не включено.

## Flip TTA для pretrained ViT

`vit_tta.py` поддерживает оба ViT. Проверка использует отдельную копию лучшего checkpoint и не останавливает обучение:

```bash
.venv/bin/python vit_tta.py --parent output/pretrained-vit-resume-20261015 --output output/pretrained-tta-check
```

На сохранённой EMA эпохи 6 проверены те же 103500 val-примеров. Без TTA: 78549 верных, accuracy 0.75892754. Усреднение вероятностей original/flip: 78760 верных, accuracy 0.76096618. Прирост — 211 верных ответов, 0.204 процентного пункта. До val-порога строго выше 0.76102 не хватает 6 верных ответов.

## EfficientNet-B3

ViT остановлен по запросу пользователя после 9 полных эпох. Последняя точка продолжения — `output/pretrained-vit-resume-20261015/last.pth`, эпоха 10, батч 1. Оптимайзер, EMA и генераторы случайных чисел сохранены; копия checkpoint перенесена на Mac, SHA256 совпадает. Лучшие веса ViT остаются EMA эпохи 6.

Общий цикл `pretrained_vit.py` также поддерживает `efficientnet_b3.ra2_in1k`: веса ImageNet-1k, новая голова на 345 классов, 11226497 параметров. Для сравнения с ViT используется вход 224×224. Чёрные линии на белом фоне повторяются в трёх RGB-каналах и нормализуются штатными mean/std ImageNet. Модель использует channels last, dropout=0.2 и DropPath=0.1.

```bash
.venv/bin/python -u pretrained_vit.py --model efficientnet_b3.ra2_in1k --output output/efficientnet-b3-20261015
.venv/bin/python pretrained_vit.py --verify --output output/efficientnet-b3-20261015
.venv/bin/jupyter lab efficientnet_results.ipynb
```

Batch size 64, AdamW: lr=0.0001 для backbone, 0.001 для головы, weight decay=0.01, warmup половину эпохи и cosine schedule. EMA=0.99, label smoothing=0.05, bfloat16 autocast. Данные и аугментации совпадают с ViT. Каждая эпоха проверяется на всех 103500 val, отдельно для текущих весов и EMA; в конце сравниваются обычный inference и flip TTA.

В коротком замере на RTX 4070 Ti batch 64 дал около 645 изображений/с и пик выделенной памяти 5474 MiB. Это замер нескольких шагов с аугментациями и оптимайзером; он не заменяет длительность полной эпохи с val. Batch 128 оказался медленнее и расходовал почти всю VRAM, поэтому выбран 64.

Полное состояние сохраняется каждую минуту в `last.pth`, лучшие веса — в `model.pth`. Результаты и архив EfficientNet хранятся отдельно; предыдущие результаты ViT и ResNet сохраняются.

Первый запуск завершил 5 эпох. Лучший checkpoint — EMA эпохи 5: 78433/103500 (0.75780676) без TTA и 78654/103500 (0.75994203) с flip TTA. Отдельная проверка повторила полный val/test: accuracy совпала, все 172500 предсказаний submission совпали. Выполненный ноутбук — `efficientnet_results.ipynb`, результаты — `output/efficientnet-b3-20261015`.

Продолжение сохраняет AdamW, EMA и историю из `last.pth`. После завершившегося cosine schedule learning rate задаётся заново: 0.00001 для backbone и 0.0001 для головы с уменьшением за три дополнительные эпохи. Данные, вход и аугментации остаются прежними.

```bash
.venv/bin/python -u pretrained_vit.py --resume output/efficientnet-b3-20261015 --output output/efficientnet-b3-resume-20261015 --resume-lr 0.00001 --epochs 3
.venv/bin/python pretrained_vit.py --verify --output output/efficientnet-b3-resume-20261015
```

`--epochs` ограничивает число дополнительных эпох, `--deadline` сохраняет общий лимит времени. По умолчанию learning rate полного resume берётся из оптимизатора; `--resume-lr` явно начинает новый cosine schedule, сохраняя накопленные состояния AdamW. Новый запуск и архив не перезаписывают первый результат. Продолжение завершило эпохи 6–8. Лучшим остался EMA checkpoint эпохи 6: 0.75879227 без TTA, 0.76026087 с flip TTA. Независимый процесс подтвердил полный val и все 172500 меток test без расхождений. Выполненный ноутбук — `efficientnet_resume_results.ipynb`.
