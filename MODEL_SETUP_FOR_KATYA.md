# Сетап моделей для Quick, Draw!

Подготовлено 17 октября 2026. Здесь собраны проверенные результаты до ConvNeXt EMA11 включительно. Последующие эпохи в этот срез не входят. Все проценты ниже — accuracy на val, а не оценка Kaggle.

Код: [TKars/computer-vision-2026](https://github.com/TKars/computer-vision-2026).

## Данные и сравнение

345 классов, исходные изображения 28×28, test — 172 500 изображений без меток.

Исходная разбивка: train 586 500 и val 103 500, по 1700/300 изображений каждого класса. Для новых опытов оставили по 100 изображений каждого класса из исходного val, остальные 200 перенесли в train. Seed разбивки — 45; исходный train сохранили целиком.

Получилось **655 500 train / 34 500 val**, по 1900/100 изображений каждого класса. Оба ViT и ConvNeXt дообучались на новом train. EfficientNet обучался раньше, на исходных 586 500; его предсказания для сравнения выбраны по индексам тех же оставленных 34 500 val.

Все модели стартовали с внешних pretrained-весов. При дообучении использовались только размеченные train-примеры. Test использовался для inference.

Checkpoint, параметры обучения и веса ансамбля выбирались по val. Кроме того, оставленный val входит в прежний val, уже использовавшийся для выбора старых моделей. Поэтому это рабочая оценка для сравнения экспериментов, а не независимый тест.

## Обычный ViT-S/16

- Batch 64, AdamW: backbone LR `1e-4`, head LR `1e-3`, weight decay `0.01`.
- Warmup половина эпохи, затем cosine; минимальный LR backbone `1e-6`, head `1e-5`.
- Cross-entropy с label smoothing `0.05`, EMA decay `0.99`, BF16 autocast, seed 45.
- Обычное перемешивание train, без class weights и mixup.
- Инверсия изображения, bicubic resize до 224×224 с `align_corners=False`, значения ограничиваются диапазоном `[-1, 1]`.
- На train: affine-поворот ±10°, масштаб 0.9–1.1, сдвиг ±0.1, случайное горизонтальное отражение с вероятностью 0.5. Affine применяется на исходном разрешении перед увеличением.

Обучили 10 эпох. Лучший EMA получился на шестой; дальше val постепенно снижался. Продолжение с меньшим адаптивным LR лучший результат не улучшило.

## Второй ViT: похожие классы в батчах

Архитектура, preprocessing, AdamW, label smoothing и EMA те же. Это отдельный старт с внешнего pretrained, а не продолжение обычного ViT.

В каждом полном батче: **48 обычных примеров + 8 из одного класса + 8 из похожего класса**. Пару выбираем равновероятно из фиксированного списка. Внутри батча дублей нет; между батчами повторы возможны. За эпоху делается 655 500 выборок, но не обязательно столько разных изображений: частоты классов меняются.

Список содержит 149 пар для 189 классов. Его получили из взаимных ошибок прежних ViT и EfficientNet на 69 000 примерах, перенесённых в новый train. Оставшиеся 34 500 val в подсчёт пар не входили.

Scheduler здесь другой: warmup 5121 шаг, затем `ReduceLROnPlateau` по EMA accuracy, `factor=0.5`, `patience=1`, абсолютный порог `0.0005`; минимальные LR `1e-6` / `1e-5`.

Loss остался обычной cross-entropy с label smoothing 0.05. Отдельного contrastive/pairwise-loss нет. Одновременно менялись sampler и scheduler, поэтому эффект только sampler этим опытом не изолирован. Одиночная модель получилась слабее обычного ViT, но дала небольшой прирост в ансамбле.

## EfficientNet-B3

- Batch 64, AdamW, weight decay `0.01`, label smoothing `0.05`, EMA `0.99`, BF16, seed 45.
- Первые 5 эпох: backbone LR `1e-4`, head LR `1e-3`, warmup половина эпохи и cosine.
- Затем 3 эпохи продолжения с восстановлением AdamW и EMA: стартовые LR `1e-5` / `1e-4`, cosine. Лучший checkpoint — EMA эпохи 6.
- Dropout `0.2`, DropPath `0.1`.
- Инверсия и bicubic resize до 224×224. Серый канал повторяется три раза; затем ImageNet-нормировка: mean `(0.485, 0.456, 0.406)`, std `(0.229, 0.224, 0.225)`.
- Train-аугментации такие же, как у ViT: ±10°, scale 0.9–1.1, translation ±0.1, случайный horizontal flip.

Важно для воспроизведения: хотя pretrained-конфигурация B3 предполагает больший вход, в этом опыте фактически использовали **224×224**.

## ConvNeXt Tiny

Основу конфигурации взяли из Катиного ноутбука: вход 128, batch 256, mixup, DropPath, OneCycle и EMA. У нас используется разбивка 95/5, полный val после каждой эпохи и BF16.

- Batch **256**, AdamW с общим LR **`5e-4`**, weight decay **`0.05`**.
- OneCycleLR на план из **20 эпох**, `pct_start=0.1`. В этом файле разобран сохранённый checkpoint эпохи 11.
- DropPath **0.3**, mixup **Beta(0.2, 0.2)**, label smoothing **0.1**.
- Mixup-loss: `lambda * CE(logits, y) + (1-lambda) * CE(logits, y_permuted)`, обе CE со smoothing 0.1.
- EMA decay `min(0.9995, (1 + step) / (10 + step))`.
- BF16 autocast; параметры, EMA и состояния AdamW в FP32. Seed 2.
- Обычное перемешивание train, одинаковый вес всех классов.
- Нормировка **`2 * pixel / 255 - 1`**, без инверсии. На val — bilinear resize до 128×128.
- На train affine сразу выводит изображение 128×128: поворот ±15°, scale 0.9–1.1, translation ±0.1. Случайного горизонтального отражения нет.

На RTX 4070 Ti 12 ГБ полный train + две проверки val (текущие веса и EMA) занимал около **6.1 минуты на эпоху** без параллельного inference. По `nvidia-smi` процесс занимал около **6.3 ГиБ**. При одновременном расчёте других моделей эпохи были дольше.

## Одиночные модели на одинаковом val

Flip TTA означает среднее двух распределений вероятностей: для исходного и горизонтально отражённого изображения.

| Модель | Без TTA | Flip TTA |
|---|---:|---:|
| Обычный ViT, EMA6 | 76,2667% | 76,3826% |
| Второй ViT, EMA6 | 75,0261% | 75,3565% |
| EfficientNet-B3, EMA6 | 76,0116% | 76,2522% |
| ConvNeXt Tiny, EMA11 | **78,1362%** | 78,0261% |

У ConvNeXt этого checkpoint отражение немного ухудшило результат.

## Ансамбли

Смешиваем вероятности классов, не жёсткие ответы. Отдельную модель поверх предсказаний не обучали.

Если используется температура T, сначала преобразуем вероятности каждой модели: `p_T = p^(1/T) / sum(p^(1/T))`. Затем считаем взвешенную сумму и берём argmax. При T=1 используются исходные вероятности.

| Вариант | Веса | Режим | Верно / 34 500 | Accuracy |
|---|---|---|---:|---:|
| Обычный ViT + EfficientNet | 40% / 60% | Flip TTA, T=4 | 26 777 | 77,6145% |
| Обычный ViT + EfficientNet + ConvNeXt EMA11 | 30% / 25% / 45% | Без TTA, T=1 | 27 112 | 78,5855% |
| Обычный ViT + EfficientNet + второй ViT + ConvNeXt EMA11 | 24% / 20% / 20% / 36% | Без TTA, T=1 | **27 149** | **78,6928%** |

Для последних вариантов сравнивали шесть фиксированных смесей: равные доли и вес второго ViT 0/5/10/15/20%, с сохранением отношения остальных трёх моделей ViT/EfficientNet/ConvNeXt = 30/25/45. С учётом T=1/2/4 и plain/flip получилось 36 вариантов. Это небольшой набор рецептов, не полный поиск оптимума.

Удаление второго ViT из последнего ансамбля и перенормировка остальных весов дали **−37 правильных ответов, или −0,1072 п.п.** на val. Для обоих вариантов собраны отдельные CSV на 172 500 test-примеров. Предсказания повторно собраны из сохранённого рецепта и проверены без различий; подтверждённых Kaggle-score в этом документе нет.

## Что оказалось полезно

- ConvNeXt в этом срезе дал лучший одиночный результат, а его добавление улучшило ансамбль.
- У обычного ViT после шестой эпохи val снижался, поэтому для inference сохранили EMA6.
- Подмешивание похожих классов не улучшило одиночный ViT; его вклад в ансамбль оказался небольшим. Для проверки самого sampler нужен опыт с одинаковым scheduler.
- Flip TTA стоит проверять отдельно для каждой модели и смеси: улучшение отдельных ViT/EfficientNet не гарантирует улучшения ансамбля с ConvNeXt.
