## План разбивки 95/5

Объём всех выданных размеченных данных — 690000. Разбивка 95/5 означает train 655500 и val 34500: по 1900 и 100 рисунков каждого класса.

Предлагаемый способ: с seed 45 оставить по 100 примеров каждого класса из прежнего val, остальные 200 перенести в train. Старый train оставить целиком. Сохранить индексы и контрольные суммы; исходные `.npy` не перезаписывать. Это пока план, индексы ещё не созданы.

После такого переноса старый val из 103500 уже нельзя использовать как честную оценку новой модели: 69000 его примеров окажутся в обучении. Для сравнения пересчитать сохранённые старые модели на одних и тех же оставленных 34500. Прежний val уже использовался для подбора моделей и весов ансамбля, поэтому новая его часть не является независимым тестом.

При новой разбивке случайным перемешиванием всех данных нельзя использовать наш старый дообученный checkpoint, если новый val содержит его бывшие train-примеры. Безопасный начальный вариант нового эксперимента — внешние pretrained-веса. Пользователь разрешил внешние pretrained-веса; дообучение только на выданных размеченных данных, без обучения на test.
